# 09. システム設定(System)

**System** タブ配下。機器自体の管理・保守・監視に関する設定です。

## 1. Admin Security(管理者設定)

| 項目 | 意味 | 変更すると起きること・注意点 |
|---|---|---|
| Admin User Name / Password | 管理者アカウント | 初期値からの変更は必須。フリートで共通ポリシーを決めておく |
| Read-only User | 閲覧専用アカウント | 現場スタッフに状態確認だけさせたい場合に有効。設定変更は不可 |
| Web Session Timeout | 無操作でのログアウト時間 | 短すぎると作業中に切れる、長すぎると放置端末リスク |
| Security(HTTP/HTTPS) | 管理画面のプロトコル | HTTPS推奨。HTTPを無効にすると平文アクセス不可 |
| Web Admin Port | 管理画面のポート | 変更したら次回から `https://IP:ポート` でアクセス |
| Web Admin Access | LAN Only / LAN+WAN | **WANに開ける場合は必ずアクセス元IP制限(Allowed Source)と強固なパスワードをセットで**。全開放は厳禁 |
| API Access(対応FW) | Router APIの有効化 | 外部ツールから設定・状態を取得する場合に有効化([設定管理UI構想](design/設定管理UI構想.md)参照) |

## 2. InControl(クラウド管理)

- **InControl Management** を有効にすると、Peplinkのクラウド(InControl2)から
  遠隔での状態監視・設定・ファームウェア一括管理ができます。
- **注意点**: InControl2で管理設定を行うと、**ローカルWeb GUIの該当項目が
  InControl2側の値で上書き**されます。「ローカルで直したのに戻ってしまう」場合は
  IC2側のグループ/デバイス設定を確認してください。
- 保証・サブスクリプション(PrimeCare等)の有効期限が切れるとIC2機能が制限されます。

## 3. Firmware(ファームウェア更新)

| 項目 | 意味・注意点 |
|---|---|
| Check for Firmware / Manual Upgrade | オンライン更新 / ファイル指定更新 |
| 更新の挙動 | ダウンロード→書込み→**再起動(通信断あり)**。所要5〜10分程度 |
| 2バンク構成 | Peplinkは新旧2面のファームウェアを保持しており、起動失敗時は旧バージョンで起動可能(System > Reboot で起動面を選択) |

- **運用上の推奨**: フリート全台で同一バージョンに揃える。SpeedFusion両端の世代差は
  トンネル互換性問題の原因になります。本番期間中の更新は避け、
  リリースノートを確認してから計画的に実施してください。

## 4. Time / Schedule

| 項目 | 意味 | 注意点 |
|---|---|---|
| Time Zone / NTP Server | 時刻同期 | **ログの時刻精度・スケジュール機能の前提**。Asia/Tokyoに設定 |
| Schedule | 時間帯による機能のON/OFF(WAN、SSID、再起動) | 「深夜に自動再起動」等。意図しない時間帯断の原因にもなるため設定の棚卸しを |

## 5. 通知・ログ・監視

| 項目 | 意味 | 変更すると起きること |
|---|---|---|
| Email Notification | イベント(WAN断、フェイルオーバー等)のメール通知 | SMTPサーバー設定が必要。Test Emailで疎通確認可能 |
| Event Log(Remote Syslog) | イベントログの外部Syslogサーバー転送 | 機器再起動でもログが失われず、集中監視できる |
| SNMP | SNMPv1/v2c/v3での監視 | 監視システム(Zabbix等)から状態・トラフィックを取得可能に |
| Controller(対応FW) | SNMPやAPI関連 | 使用しない管理プロトコルは無効のままが安全 |

## 6. Configuration(設定の保存・復元)

| 操作 | 意味・注意点 |
|---|---|
| Download Active Configurations | 現在の設定をファイルで保存。**変更作業前の必須手順** |
| Restore Configuration | ファイルから復元。再起動を伴う |
| Restore Factory Settings | 工場出荷状態へ初期化。**全設定消滅**。実行前に必ずバックアップ |

## 7. Tools / Reboot

| 項目 | 用途 |
|---|---|
| Ping / Traceroute | 指定WANインターフェースを選んで疎通確認できる(**回線単体の切り分けに極めて有効**) |
| WAN Analysis | 対向Peplinkとの間で回線品質を測定 |
| Reboot | 再起動。起動ファームウェア面(2バンク)の選択もここ |

## 8. GPS(Status > GPS)

- 現在位置・衛星捕捉状況の確認。外部への位置送信は [07章](07_詳細設定.md) の GPS Forwarding で設定します。
