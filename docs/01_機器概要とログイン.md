# 01. 機器概要とログイン・基本操作

## 1. 機器の位置づけ

MAX BR2 Pro / MAX Transit Pro Duo はいずれも「複数のWAN回線(セルラー×2、有線WAN、Wi-Fi WAN)を
束ねて使う」ことを目的としたボンディングルーターです。設定項目は大きく次の5系統に分かれます。

1. **WAN側**: 各回線(セルラー/有線/Wi-Fi WAN)ごとの接続設定と、回線の使い分けルール
2. **VPN(SpeedFusion)**: 複数回線を1本の仮想回線に束ねるボンディング設定
3. **LAN側**: 配下の機器に配るネットワーク(IP、DHCP、VLAN)
4. **AP(Wi-Fi)**: ルーター自身が吹くWi-Fi
5. **システム**: 管理者、ファームウェア、監視・通知

**どの画面の設定がどこに効くのか**を意識すると迷子になりにくくなります。
「インターネットに出ていく通信の挙動」を変えたいならWAN/詳細設定、
「配下の機器への配布」を変えたいならLAN/AP、が基本です。

## 2. Web管理画面へのログイン

| 項目 | 内容 |
|---|---|
| アクセスURL | `https://192.168.50.1`(工場出荷時のLAN IP。変更済みの場合はそのIP) |
| 初期ユーザー | `admin` / `admin`(初回ログイン時にパスワード変更を要求されます) |
| 証明書警告 | 自己署名証明書のためブラウザが警告を出しますが、そのまま進んで問題ありません |

- LANポートまたは本体Wi-Fiに接続した端末からアクセスします。
- WAN側からのアクセスは初期状態で無効です(有効化は [09. システム設定](09_システム設定.md) の Admin Security)。
- InControl2(クラウド管理)配下にある機器は、**InControl2側の設定が優先**され、
  ローカルで変更しても同期のタイミングで上書きされる項目があります。どちらで管理するかを
  組織内で統一しておくことが重要です。

## 3. 最重要: 「Save」と「Apply Changes」の2段階適用

Peplinkの管理画面は、設定変更が**即時には反映されません**。

1. 各設定ページで **Save** を押す → 変更が「保留」状態になる
2. 画面右上に赤い **Apply Changes** ボタンが出る → これを押して初めて機器に反映される

| 操作 | 起きること |
|---|---|
| Save のみ | 変更は保留。他のページの変更もまとめて保留できる |
| Apply Changes | 保留中の変更を一括反映。**項目によっては該当WANの再接続やサービス再起動が発生** |
| Apply せずログアウト/放置 | 保留中の変更は破棄される場合がある(反映されない) |

> **運用上のコツ**: 複数ページにまたがる変更は、すべてSaveしてから最後に1回だけApplyすると
> 切断回数を最小化できます。逆に「Saveしたのに反映されない」場合はApply忘れを疑ってください。

## 4. 作業前の必須手順: 設定バックアップ

**System > Configuration > Download Active Configurations** から現在の設定ファイル(.conf)を
ダウンロードできます。設定変更作業の前には必ず取得してください。

- 復元は同じ画面の **Restore Configuration** から。復元時は再起動が入ります。
- 設定ファイルは機種・ファームウェア世代が近いほど互換性が高く、
  **同一機種間ならほぼそのまま移植可能**です(2台目の同型機を同じ構成にする際に便利)。

## 6. 変更の影響度の目安

| 影響度 | 例 | 反映時の挙動 |
|---|---|---|
| 低(無停止) | 通知設定、ログ設定、管理者パスワード | 即時反映、通信影響なし |
| 中(部分断) | WANのヘルスチェック、APN、アウトバウンドポリシー | 該当WANの再接続、既存セッションの張り直し |
| 高(全断あり) | LAN IP変更、VLAN構成、ファームウェア更新、再起動 | 全体の通信断・管理画面への再接続が必要 |

各マニュアルの「注意点」欄に、この影響度を記載しています。
