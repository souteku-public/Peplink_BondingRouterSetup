# 08. AP(Wi-Fi)設定

**AP** タブから、ルーター自身が吹くWi-Fi(アクセスポイント機能)を設定します。
両機種ともデュアルバンド(2.4GHz / 5GHz)のWi-Fi 6対応です。

## 1. Wireless SSID(SSIDごとの設定)

SSIDは複数作成できます(業務用・ゲスト用の分離など)。

| 項目 | 意味 | 変更すると起きること・注意点 |
|---|---|---|
| SSID | ネットワーク名 | 変更すると全端末が再接続必要 |
| Enable | SSIDの有効/無効 | 一時的に電波を止めたい時に使用 |
| VLAN | このSSIDを所属させるVLAN | [06章](06_LAN_ネットワーク設定.md)のVLANと組み合わせてネットワーク分離 |
| Broadcast SSID | SSID名を公開するか | 非公開(ステルス)にしても実質的なセキュリティ向上は限定的 |
| Security Policy | 認証方式 | **WPA2/WPA3-Personal または WPA3 を推奨**。WPA/WEPは使用しない。WPA3 Onlyにすると古い端末が接続不可 |
| Shared Key | パスフレーズ | 変更すると全端末が再接続必要 |
| Guest Protect(Layer 2 Isolation) | 同一SSID内の端末同士の通信を遮断 | ゲスト用SSIDでは有効を推奨。業務機器同士が通信するSSIDでは無効 |
| Maximum Number of Clients | 接続台数上限 | 過密環境で品質を保つために制限可能 |
| Band Selection | 2.4GHz / 5GHz のどちらで吹くか | 5GHzのみにすると高速だが到達距離・障害物耐性は低下 |

## 2. Settings(無線の物理設定・バンド単位)

| 項目 | 意味 | 変更すると起きること・注意点 |
|---|---|---|
| Protocol / Operating Mode | 802.11規格(ax/ac/n...) | 通常は既定(最新+互換)。固定すると古い端末が接続不可になる場合あり |
| Channel | 使用チャンネル | Autoが基本。干渉源が特定できている常設環境では固定が有効。**5GHzのDFSチャンネルはレーダー検知で強制チャンネル移動(瞬断)が起きる**ため、瞬断を嫌う用途ではW52(36-48)固定を検討 |
| Channel Width | 帯域幅(20/40/80MHz) | 広いほど高速だが干渉に弱い。過密環境では20/40MHzの方が安定することも |
| Output Power | 送信出力 | 狭い現場で複数APが近接する場合は下げると干渉が減る |

## 3. Wi-Fi WAN との共存(重要)

Wi-Fi WAN([03章](03_WAN設定.md))を使う場合、**同じ無線チップをAPと共有**します。

- **起きること**: Wi-Fi WANが接続した先のチャンネルに、自機のAPも引きずられます。
  APのチャンネル固定設定は事実上無効になります。
- Wi-Fi WAN接続中はAPのスループットも影響を受けます。
  帯域が必要な場合は「Wi-Fi WANは2.4GHz、APは5GHz」のようにバンドを分けるのが定石です。

## 4. Mesh / WDS(対応ファームウェア)

- 複数のPeplink APで網目状にエリアを拡張する機能。単体運用では使用しません。

## 5. 運用のヒント

- **接続中クライアントの確認**: Status > Client List。端末ごとの帯域使用量も見えます。
- 「Wi-Fiが遅い」の切り分けは、(1) Client Listで台数過多を確認 →
  (2) RSSI(端末の受信強度)確認 → (3) チャンネル干渉(周辺AP調査)→ の順が効率的です。
- 中継現場など**Wi-Fiを使わない運用ではAPを無効化**すると、干渉源にならずセキュリティ面でも安全です。
