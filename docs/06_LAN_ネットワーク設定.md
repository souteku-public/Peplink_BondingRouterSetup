# 06. LAN・ネットワーク設定

**Network > LAN** から設定します。配下の機器(PC、エンコーダー、カメラ等)に
どのようなネットワークを提供するかを決める領域です。
**この領域の変更は自分自身の管理画面アクセスを切断し得る**ため、影響度が高い操作が多い点に注意してください。

## 1. Network Settings(LAN基本設定)

### LAN IP Address / Subnet Mask

- ルーター自身のLAN側IPアドレス(既定: `192.168.50.1/24`)。
- **変更すると起きること**: LANの全機器のネットワークが変わります。DHCPで配る範囲も
  連動して見直しが必要です。**Apply直後から旧IPでは管理画面に入れなくなる**ため、
  変更後のIPへアクセスし直してください。
- **注意点**: 複数台のPeplinkを運用する場合、機器ごとにLANセグメントを変えておくと
  誤接続時の事故(IP重複)を防げます。

### DHCP Server

| 項目 | 意味 | 変更すると起きること |
|---|---|---|
| DHCP Server(有効/無効) | 配下へのIP自動配布 | 無効にすると全機器を固定IP運用にする必要がある |
| IP Range | 配布範囲 | 固定IPで使いたいアドレスは範囲外に置く |
| Lease Time | 貸出期間 | 短くすると入れ替わりの激しい環境でアドレス枯渇を防げる |
| DNS Servers | 配下に通知するDNS | 既定はルーター自身。特定DNSを強制したい場合に変更 |
| Reservation(DHCP予約) | MACアドレスに固定IPを割当 | エンコーダー等「IPが変わると困る機器」はここで固定するのが定石(機器側は DHCP のままでよい) |

### Extended DHCP Option

- NTPサーバー通知(Option 42)など、DHCPで追加情報を配る上級者向け設定。通常は未使用。

## 2. VLAN

「Network Settings」の「New LAN」からVLANを追加できます。

| 項目 | 意味 | 変更すると起きること |
|---|---|---|
| VLAN ID | VLANタグ番号 | タグVLAN対応スイッチと連携する場合は一致させる |
| IP / DHCP | VLANごとのセグメントとDHCP | VLANごとに独立したネットワークを配布 |
| Inter-VLAN Routing | VLAN間の通信を許可するか | **無効にするとVLAN間は遮断**。ゲスト用・業務用の分離に使用 |

- 各SSID([08](08_AP_WiFi設定.md))・各LANポートをどのVLANに所属させるかは、
  それぞれの設定画面で指定します。
- **用途例**: 「業務機器用VLAN」と「スタッフ/ゲストWi-Fi用VLAN」を分け、
  Inter-VLAN Routingを無効にして相互アクセスを遮断する。

## 3. Port Settings(物理LANポート)

| 項目 | 意味 | 変更すると起きること |
|---|---|---|
| Port Type: Trunk | タグ付きで複数VLANを通す | VLAN対応スイッチへの接続用 |
| Port Type: Access | 指定VLANのみタグなしで通す | 通常機器の接続用。所属VLANを選択 |
| Speed | 速度固定 | 通常Auto。不整合に注意([03章](03_WAN設定.md)と同様) |
| Enable | ポートの有効/無効 | 無効にしたポートは物理的に不通になる |

- **注意点**: 管理端末が繋がっているポートをAccessで別VLANに変更すると、
  Apply直後に管理画面へ到達できなくなります。

## 4. Static Route(静的ルート)

- LAN側にさらにルーターがぶら下がる構成で、その先のセグメントへの経路を登録します。
- **変更すると起きること**: 登録した宛先ネットワークへの通信が指定ゲートウェイに向かいます。
  誤登録すると該当宛先だけ通信不能になる「部分的な障害」となり、気づきにくい点に注意。

## 5. DNS Proxy / Local DNS Records

| 項目 | 意味 | 用途 |
|---|---|---|
| DNS Proxy | 配下からのDNS問合せをルーターが代理解決 | 既定で有効。WAN切替時もDNS設定変更が不要になる |
| Local DNS Records | ルーターに静的な名前→IPを登録 | LAN内機器に名前でアクセスしたい場合 |
| DNS Caching | 解決結果のキャッシュ | 有効で応答高速化。検証でレコードを頻繁に変える時は無効化 |

## 6. Captive Portal(対応ファームウェア)

- Wi-Fi接続時に同意画面・認証画面を挟む機能。ゲスト向けSSIDに適用します。
- **注意点**: 業務機器のSSIDに誤って適用すると、機器が認証画面を通過できず通信不能になります。
