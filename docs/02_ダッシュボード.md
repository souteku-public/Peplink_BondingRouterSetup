# 02. ダッシュボード(Dashboard)

ログイン直後に表示される画面です。**日常運用で最も使う画面**であり、
ここだけで「回線の優先順位の変更」「回線の手動接続/切断」ができます。

## 1. WAN接続リスト

各WAN(Cellular 1 / Cellular 2 / WAN(有線) / Wi-Fi WAN / USB)が優先度順に表示されます。

### 状態表示の見方

| 表示 | 意味 |
|---|---|
| 緑「Connected」 | 接続済み。優先度に応じてトラフィックを流せる状態 |
| 黄「Connecting...」 | 接続処理中(セルラーの場合はキャリア接続・APN認証中) |
| 「Standby」 | 待機中。上位回線が生きているため使われていない(接続維持のホットスタンバイか、切断のコールドスタンバイかはWAN詳細設定による) |
| 赤「Disconnected」/「No SIM Card Detected」等 | 切断・障害。理由が併記される |
| 「Health Check Failed」 | 物理的には接続しているが、ヘルスチェック(疎通確認)に失敗し「死んだ回線」と判定されている |

### 優先度(Priority)の操作

- 各WANは **P1 / P2 / P3...** の優先度グループにドラッグ&ドロップで移動できます。
- **変更すると起きること**:
  - **P1(最上位)**: 通常時にトラフィックが流れる回線。P1に複数回線を置くと、
    アウトバウンドポリシー([07](07_詳細設定.md))に従って**負荷分散**されます。
  - **P2以下**: P1の全回線がダウンした時のみ使われる**フェイルオーバー回線**。
  - **Disabled(最下段)**: その回線を完全に無効化。接続試行もしなくなります。
- **注意点**:
  - 優先度変更もApply対象です。反映時に該当回線の再接続が入ることがあります。
  - SpeedFusionトンネルに使う回線の優先度は、トンネル側のWAN設定([05](05_SpeedFusion_VPN.md))が
    別に存在します。ダッシュボードの優先度は「トンネルを通らない生のインターネット通信」への設定です。

### Connect / Disconnect ボタン

- 回線単位で手動接続・切断ができます。
- **変更すると起きること**: Disconnectした回線は手動でConnectするまで復帰しません
  (再起動でも状態が保持される場合があります)。
- **注意点**: 「検証で一時的に切りたい」用途に便利ですが、**戻し忘れが最も多い操作**です。
  恒久的に使わない回線は優先度をDisabledにする方が安全です。

### Details リンク

各WANの「Details」をクリックすると、そのWANの詳細設定([03](03_WAN設定.md)、
セルラーは[04](04_セルラー設定.md))に直接移動できます。
セルラーの場合はここで電波強度(RSRP/RSRQ/SINR)、接続バンド、キャリア名、SIMスロット状態が確認できます。

## 2. SpeedFusion 状態表示

設定済みのSpeedFusion/PepVPNプロファイルの接続状態(Established / Connecting / Failed)が表示されます。

- クリックすると各トンネルの詳細(使用中のWAN、スループット、レイテンシ)に移動します。
- ライブ配信・中継前の確認では、**Established であること**と、
  **意図した本数のWANがトンネルに参加していること**の2点を見ます。

## 3. デバイス情報パネル

| 項目 | 見るポイント |
|---|---|
| Firmware | 現行バージョン。フリート内で揃っているか |
| Uptime | 意図しない再起動が起きていないか(短すぎる場合は電源・熱を疑う) |
| CPU / Throughput | 負荷状況。スループット上限に張り付いていないか |
