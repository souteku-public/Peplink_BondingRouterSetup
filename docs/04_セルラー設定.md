# 04. セルラー設定(Cellular 1 / Cellular 2)

ダッシュボードの Cellular の「Details」、または **Network > WAN > Cellular** から設定します。
両機種ともセルラーモデムを2基搭載しており、**モデムごとに独立して**この設定を持ちます。

- MAX BR2 Pro: Cellular 1 / Cellular 2(各モデムに冗長SIMスロット)
- MAX Transit Pro Duo: Cellular 1(CAT-7) / Cellular 2(CAT-12)、各モデム2スロット(SIM A/B)

## 1. SIM スロット関連

### SIM Card(使用スロットの選択)

| 設定値 | 意味 | 変更すると起きること |
|---|---|---|
| Both SIMs(既定) | A/B両方を使い、障害時に自動で切替 | 片方のSIMが圏外・認証失敗・データ上限到達のとき、もう片方に自動フェイルオーバー |
| SIM A Only / SIM B Only | 指定スロットのみ使用 | もう片方は完全に無視される。検証時やキャリア固定運用向け |
| Alternate between SIM A and SIM B periodically | スケジュールに従いA/Bを定期的に交互使用 | データ量を両SIMに分散したい契約向け。切替時に再接続断が発生する点に注意 |

- **Preferred SIM**: Both選択時にどちらを優先するか。
- **注意点**: SIM切替は**モデムの再接続を伴う**ため数十秒の断が発生します。
  切替を自動に任せる場合は、両スロットのAPN設定がそれぞれ正しいことを事前に確認してください。

### SIM PIN

- SIMにPINロックがかかっている場合のみ入力。誤ったPINを保存すると、
  再試行の繰り返しで**SIMがPUKロックされる恐れ**があります。PINなし運用を推奨。

## 2. 接続先・APN 設定

### APN(Access Point Name)

| 設定値 | 意味 | 変更すると起きること |
|---|---|---|
| Auto(既定) | SIMから判別して内蔵データベースのAPNを使用 | 大手キャリアSIMはほぼこれで接続可 |
| Custom | APN名・ユーザー名・パスワード・認証方式を手動指定 | MVNO・法人閉域SIMでは必須。誤入力すると「Connecting」のまま接続できない |

- **注意点**: SIMスロットごと(SIM A/B別々)にAPNを設定します。
  「SIM Aでは繋がるがBに切り替わると繋がらない」場合、B側のAPN未設定を最初に疑ってください。

### Data Roaming(データローミング)

- 既定は無効。海外SIM・ローミング前提の回線契約では有効化が必要です。
- **変更すると起きること**: 有効にすると契約外の高額ローミング通信が発生するリスクがあるため、
  国内キャリアSIMでは無効のままにしてください。

### Carrier Selection(キャリア選択)

- **Auto(既定)**: SIMに応じて自動選択。
- 手動選択は、ローミングSIMで意図しない事業者網を掴む場合に使用。
- **注意点**: 手動固定した事業者が圏外のエリアに移動すると、自動で他網に逃げられなくなります。
  移動運用(中継車等)ではAutoを推奨。

## 3. ネットワークモード・バンド固定

### Network Mode

| 設定値 | 変更すると起きること |
|---|---|
| Auto(既定) | 5G/LTE/3Gを自動選択(対応モデムの場合) |
| LTE Only 等 | 指定世代に固定。5G⇔LTE間のハンドオーバーによる瞬断を避けたい場合や、不安定な5Gエリアで安定性を優先する場合に有効 |

### Band Selection(バンド固定)

- モデムが使用するLTE/5Gバンド(B1, B3, B8, n78 など)をチェックボックスで限定できます。
- **変更すると起きること**: 混雑したバンドや電波の弱いバンドを除外することで、
  スループット・安定性が改善することがあります。逆に固定しすぎると、
  移動先でどのバンドにも掴めず**圏外**になります。
- **注意点**: 固定運用(常設場所)でのみ使い、現地での電波調査結果に基づいて設定してください。
  移動運用ではAuto(全バンド)を推奨。**設定はSIMスロットではなくモデム単位**です。

## 4. 電波状態の読み方(Details画面の表示)

| 指標 | 意味 | 目安 |
|---|---|---|
| RSRP | 受信電力(電波の強さ) | -80dBm以上: 優 / -90: 良 / -100: 可 / -110以下: 不安定 |
| RSRQ | 受信品質 | -10dB以上: 良 / -15以下: 混雑・干渉の疑い |
| SINR | 信号対雑音比 | 20dB以上: 優 / 13: 良 / 0以下: 通信困難 |

- アンテナバーの本数よりも、これらの数値で判断する方が正確です。
- **RSRPが良いのに速度が出ない場合はRSRQ/SINR(混雑・干渉)を疑う** → バンド固定の検討材料。

## 5. その他の項目

| 項目 | 意味 | 変更すると起きること・注意点 |
|---|---|---|
| Bandwidth Allowance Monitor | SIMごとの月間データ量上限 | [03章](03_WAN設定.md)と同様。**SIMスロット単位**で設定でき、上限到達時にもう片方のSIMへ自動切替させる運用が可能 |
| Health Check | セルラー回線の死活判定 | セルラーで選べるのは**SmartCheckまたはDisabled**。考え方は[03章](03_WAN設定.md)参照 |
| Standby State | 待機時に接続維持するか | ボンディング/高速切替に使う回線は Remain Connected 推奨 |
| Signal Threshold(対応FW) | 電波強度による接続抑制のしきい値 | 電波が悪い時にその回線を自動で待機へ落とす。移動運用でフラッピングの原因にもなるため慎重に |

## 6. よくある落とし穴

1. **APNはスロット単位** — SIM入替時は必ず該当スロットのAPNを確認。
2. **バンド固定のまま現場を移動** — 圏外の原因が設定であることに気づきにくい。
3. **Bothスロット構成で片側だけ整備** — フェイルオーバーした瞬間に接続不能になる。
4. **上限超過Action=Disconnectの戻し忘れ** — 月替わり後も切断されたままに見えるケースは
   ダッシュボードの状態表示(Bandwidth Allowance Exceeded)で確認。
